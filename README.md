# India Alpha Terminal

India Alpha Terminal is a small, static dashboard concept for exploring how an Indian market terminal could look and feel. It is also my learning project for building a clear, responsive web interface.

## Live demo

**[Open India Alpha Terminal](https://pratik-sapkal.github.io/india-alpha-terminal/)**

The dashboard includes:

- A responsive market overview with index summary cards and an illustrative market-breadth panel
- An SVG chart with selectable sample ranges
- A searchable watchlist with up/down filters; selecting a symbol updates the chart header
- Keyboard-visible focus, a skip link, semantic landmarks, and reduced-motion support

## Important: sample data only

Every price, percentage, volume, chart point, and market-breadth value in this prototype is fictional sample data. The page does not connect to an exchange or provide live prices, market research, investment guidance, or financial advice.

## Built with

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

There is no backend, build step, or external runtime dependency. Open `index.html` in a browser to explore the interface locally.
